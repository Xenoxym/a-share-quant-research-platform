# 模型分数怎样变成持仓（E17）

假设模型给本周的股票打了分。分数0.06、0.03、-0.01只代表模型输出：不能直接把0.06写成赚了6%。接下来要明确选谁、给多少资金、何时下单，再让账户计算真实发生的成交和持仓。

本接口连接[成熟标签学习](ALPHA_CAUSAL_LEARNING.md)与现有账户。它没有重新训练模型，也没有自动开始真实数据回测；账户会计继续使用原实现。

## 一周实际如何走

1. 周末前最后一个交易日收盘后，给当时名单的每只股票评分。这里没有“先挑小市值”步骤。
2. 根据事先声明的资格名单，按分数从高到低选择top_k。并列时按股票代码升序，规则固定。
3. 每只入选股票目标权重为allocation/top_k。例如top_k=100、allocation=0.98，每只目标0.98%；只有80只合格时目标合计78.4%，其余留现金。
4. 下一交易日开盘尝试买卖。账户继续检查资金、100股单位、价格限制、停牌、容量、费用和公司行动；目标权重不是保证成交比例。
5. 下一次调仓重新评分和设目标；末日只估值，不凭空安排清仓。

月度同理，用月末交易日决定，下一交易日开盘执行。工程接口当前只连接这两种日线开盘账户规则；盘中或收盘成交研究需要另外实现。

## 学习目标与账户持有期要说清楚

当前账户按下一次调仓开盘更新持仓。例如上周五收盘决定、周一开盘买入，下一周一开盘换仓，计划持有期是两次开盘之间。它不会自动在本周五收盘卖出。

因此默认检查模型每行的目标结束时间是否为下一次计划调仓开盘。若模型预测的是“周一至周五收盘”，默认报错，提醒端点不同。只有显式允许不同预测目标时才继续，并记录不匹配数量；这属于用一种预测辅助另一种持有规则，不能宣称训练直接优化了同一段账户收益。

最后一段持仓按账户结束日估值，可能还没走完预测目标。目标时间到达也不表示涨跌停或停牌时必定能卖出。原有回测记录及其端点不会被改写。

## 全市场学习与主板账户

模型可以在更广的股票范围学习，但现有账户的交易规则核查主要覆盖主板。默认遇到更广的评分名单会拒绝；协议明确选择main_board_subset时，才取其中主板部分，并保留被排除股票及原因。

这一步不是市值筛选。资格条件由调用方提供其历史可知名单；接口核对资格可知时间、样本键和内容身份，不能凭几个时间字段认证原始数据正确。现阶段不能把这称作所有板块已支持的账户回测。

## 对错误做什么

E17增加学习收据V2的独立名单指纹，绑定样本键与决策/买入/目标时钟；没有这项字段的旧V1不能用于此接口。分数表必须与源输入、缺失表行数和名单指纹完整匹配，每只股票都有对应参考行。缺评分、少参考行、样本编号错位、未知日历日、未来才可知的收盘价、后来才可知的资格信息、非下一交易日开盘，都拒绝。预测股票仍不需要未来收益标签。

模型摘要的规范参数、特征名单、代码环境和训练标签最晚可知时间也需一致；内部一致性不是模型实际拟合或数据来源的认证。收据还绑定完整源学习收据内容，并记录评分来源、账户名单、日历、调仓日、参数、排除原因、持有端点差异和输出内容。输入分数、参考价或代码变化可以追查。同一收据被修改不能只靠原名字通过核对；文件冻结和来源真实性仍由正式研究任务与后续审计负责。

## 接口示例

```python
from src.alpharesearch.portfolio import build_score_portfolio, score_portfolio_spec

policy = score_portfolio_spec(
    start="2024-01-02", end="2025-12-31", top_k=100, allocation=.98,
    rebalance="weekly", account_universe="main_board_subset",
)
portfolio = build_score_portfolio(learning_result, references, calendar, policy)
decisions = portfolio.decisions  # 原生账户需要的完整名单、排除理由和目标权重
schedule = portfolio.schedule
receipt = portfolio.receipt
```

references含sample_id、trade_date、stock_code、reference_close、reference_close_observed_at、reference_close_known_at、eligible、eligibility_known_at。合格候选的参考价是该决策日原始收盘价，不是复权价或未来成交价。实际调用账户时，还要提供一致的ResearchSpec、冻结快照及Market；此处不伪造这些输入或自动执行。

本阶段的合成资金链检查只验证接线。下一阶段核查来源、模型和账户证据，然后由有限真实研究比较小市值、固定随机及模型对照的账户收益和回撤。
