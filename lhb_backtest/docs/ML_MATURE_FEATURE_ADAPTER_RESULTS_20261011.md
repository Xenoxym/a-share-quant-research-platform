# 把成熟Qlib公式接进我们的项目：现在能做什么

本阶段已经真实运行一次测试，**51项全部通过**。其中25项是新接口的反例和合同检查、24项是现有登记与组装回归、2项使用真实Qlib接口。独立结果复核尚待完成；这是接口接入结果，不是新的盈利策略。

## 1. 用人话说明新增的功能

以前，我们证明了Qlib能算出数字；这次把这些数字装进项目现有的特征模块，让后续代码能知道：它属于哪只股票、哪一天、是什么单位、什么时候才可用、缺失为什么发生，以及调用了哪个明确版本。

例如，某股票今天收盘10元，五个交易日前收盘12元，`Ref($close,5)/$close-1`得到0.2。它表示**过去价格相对今天高20%**，正值对应下跌；并不是过去五日上涨20%。这是模型可以使用的一个X，是否能赚钱还要另行训练并计算账户。

行情与时钟 → Qlib已有计算器 → 我们的FeatureBlock → 已有登记与决策名单组装 → 后续模型与账户验证。

这里没有再造计算器、表达式语言或安装器，也没有替换资金账户。

## 2. 接入的是哪六列

| 特征 | 人话含义 | 单位与限制 |
|---|---|---|
| close | 当日原价收盘的float32镜像 | 元/股；不等于复权价格 |
| close_lag5_ratio | 五日前收盘÷当前收盘−1 | 比率；方向是反转表达 |
| mean20_to_close | 二十日均价÷当前收盘−1 | 比率；不足20日缺失 |
| slope20_to_close | 二十日价格趋势斜率÷当前收盘 | 比率；时间单位固定为一个交易日 |
| rsquare20 | 二十日价格走势被线性趋势解释的程度 | 比率；平价窗口可能无定义 |
| resi20_to_close | 最后一天价格偏离二十日线性趋势的残差÷收盘 | 比率；不足20日缺失 |

实际验证的是固定PyQLib0.9.7的Windows/CPython 3.12发行轮子；没有验证Linux上的该后端。这里只是六个选定表达式，不是全部Alpha158、Alpha360，也不是它的完整研究/交易后端。这些列部分与既有价量特征相关，接入数量不等于新增独立Alpha。[官方固定版本的因子定义源码](https://github.com/microsoft/qlib/blob/da920b7f954f48ab1bb64117c976710de198373e/qlib/contrib/data/loader.py)

## 3. 怎样防止把错误数字送给模型

外部计算器的收盘价必须与声明行情的float32镜像逐项一致，日期和每只股票的完整声明日历必须对齐。缺少日期不能跳过去当连续交易日；非法单位、无限值、布尔值、复数或任意未来表达式会被拒绝。缺失不补零。

Qlib在历史不足窗口长度时可能给出短窗口值；我们明确把它标成历史不足。完整窗口中缺有效收盘则标成不完整；其余无定义的NaN保留原因。原价涉及公司行动的跳变仍是数据限制，本阶段没有解决复权。

当前特征块的可用时钟保守取所选特征最大依赖窗口的已知时间。例如二十日前某条数据其实更晚才可知，不能因为当天收盘已发生就提前使用。已有决策组装层会拒绝晚于决策时点的输入。这里只核声明时钟，没有独立证明供应商真实发布时间。

登记保存算法定义；物化记录保存实际输出、原输入、派生源、provider文件清单和执行代码的联系。登记中的“代码一致”仍不是认证，不能仅凭一个标识就证明外部回调确实执行了这些算法。

## 4. 实际跑了什么，没跑什么

真实集成使用原有12股×120日、1440行日线收盘的小切片；复用已安装的隔离环境和两份已有二进制行情镜像。实际调用正常与未来扰动场景共144组股票×表达式，与上一阶段已验证数组对照后，再检验新接口的完整窗口缺失处理。

未来场景把后60日价格改为人工极值；前60日的4320个特征值及其缺失、时钟保持一致。它有独立派生数据身份，明确是合成反例，使用unknown vintage；不能伪称原始真实行情。正常场景保留原数据的声明市场观察口径。

最终12只股票的六列特征成功通过现有登记与决策名单组装；同日14时决策被拒绝，因为使用了收盘后才可用的信息。实际安装成员666项再次校验、基础143项版本发现口径一致；没有新下载、安装、模型fit/predict或账户。

测试日志51 passed in 25.62s；完整受监督操作约29.33秒，采样峰值约295.27MiB、最低物理余量约14.73GiB、最低可承诺余量约7.32GiB。父与子实际加载的数值库线程均不超过2；最终自有Windows进程数0，无监督错误。这些只是小切片数据，不能外推完整A股容量或宣布收益改善。

优先接续原R25R尚未运行的日期内排名目标：同36特征、同随机森林、只新增一个模型和零费/含费两条账户，以年化收益和每日最大回撤对照原始收益目标、中心化目标、小市值等旧结果。现有6.5GiB可承诺空间/12GiB物理门槛必须在实际启动时再核；没有把这些门槛借给完整68项任务。
