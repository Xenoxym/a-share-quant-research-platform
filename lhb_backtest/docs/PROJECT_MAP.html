一周例子

示例：周五收盘后，用当时可知的信息给股票打分，按事前规则选股和分配资金；下个交易日开盘尝试调仓，随后逐日算账户。

默认学习目标是两次计划调仓开盘之间的收益，不是第五天绝对价格，也没有直接训练最大回撤。“固定随机11”的11是种子，不是股票数量。E19的日期、共同主板名单、100只目标持仓和四个对照已固定；最新实验状态见本页摘要。

接下来四步

  1. 完成原12项模型训练及结果核查；失败保留，不追加参数或重训。
  2. 沿用原模型分数，固定每周最多100只；与小市值、固定随机顺序、60日低波动、半仓小市值同时比较。
  3. 核查零交易费用与配置费用账户，以收益、最大回撤、分期表现、仓位和换手作结论。
  4. 整理全部路径和失败，双复核及选择性发布；再选择序列表示或有限自动公式/组合研究。
