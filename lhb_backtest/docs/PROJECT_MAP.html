一周例子

示例：周五收盘后，用当时可知的信息给股票打分，按事前规则选股和分配资金；下个交易日开盘尝试调仓，随后逐日算账户。

默认学习目标是两次计划调仓开盘之间的收益，不是第五天绝对价格，也没有直接训练最大回撤。“固定随机11”的11是种子，不是股票数量。E19的日期、共同主板名单、100只目标持仓和四个对照已固定；最新实验状态见本页摘要。
