# 模型究竟学到了什么？十二个模型保存分数的统一诊断

记录时间：2026-10-09T06:44:37.596496+00:00。E19D单批诊断已完成；此页用于结果复核与交付。这不是新策略成功报告，也没有新增训练或回测。

## 1. 现在能回答什么

本批十二个模型的扣费账户年化全部为负，结论不变。保存分数的诊断中，十二个模型的平均RankIC均为正，但九个模型前100只的平均后续涨幅低于同日候选名单平均值。整体排序与最前100只选股表现，需要分别检验。

本批训练目标仍是下一次周调仓开盘至再下一次周调仓开盘的参考链收益；岭回归、提升树等回归这个收益，Huber使用稳健误差。本次没有把学习目标改成RankIC。RankIC只在训练结束后检查保存分数的排序关系。正相关是这段历史中的描述，不证明稳定预测能力或未来盈利。

## 2. 用一周说清楚这次检查

每个交易周最后一个市场交易日收盘后，模型给合格主板名单中每只股票一个分数。我们保留原名单、原分数和原次序，先选前100只，再查看这些股票后一个调仓区间的Y；不知道Y的股票保留为未知，不据此删除候选或填成0。

主表只用截至账户结束日2026-09-17已走完标签区间的188次决策，共547706股票日期行，其中547701条标签已观察。完整预测有189次、550711行，其中550701条标签可观察；其最后区间延伸至账户结束之后，单列附表。标签统计可用时点固定为2026-09-24 15:30（上海时间）。

“前100只超额”计算为：当天前100只已观察Y的平均值，减去当天完整候选名单已观察Y的平均值，再将各决策日等权平均。例如候选平均涨1.00%、前100只涨1.20%，记为＋0.20个百分点。这不是年化收益，也没有逐期复利或模拟账户。

标签基于入场开盘、区间内close/pre_close参考链、退出开盘连接，避免直接用未复权端点价格比；仍继承供应商pre_close、数据覆盖及公司行动局限。实际账户包含仓位、实际买到/卖出股票、资金、公司行动、费用等路径，不能由标签均值替代。

## 7. 已完成什么，下一步为什么这样走

工程方面，正式sequence模块已新增，保留三十个旧反例并增加两个daily_primitives接口反例，32项单批检查通过。它把明确每日特征整理成“样本×过去市场交易日×特征”，保存缺失掩码和可知时间；没有训练序列模型、读取真实市场试点或新增账户。

下一步分别登记：保存未来模型权重及训练/预测分数；检查头部目标、相对收益目标与原收益目标；检验明确预算下的滚动训练、同分/持仓范围与原Top100对照；接入有限真实序列分区，比较相同X/Y下的展平模型与序列模型；将广泛公式生成、组合协同和风险配置继续留在研究路径中。每条进入实际研究时必须单独冻结预算，最后按账户收益和回撤判断。

来源学习：Qlib官方handler默认对学习标签做按日横截面标准化；DoubleAdapt论文探索数据与模型适配，使用CSI300/500与不同历史、不同目标。它们提供待检验设计，尚未在本项目复制或验证，也不能作为本项目盈利证据。
