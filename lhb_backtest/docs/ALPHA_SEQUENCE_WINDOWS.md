# 用人话看序列接口：把过去信息排成一张有时间顺序的表

## 序列接口已经做了什么

现在正式代码已有src/alpharesearch/sequence.py。32项软件检查通过，包含原30项反例及2项日线原始特征接入手算。还没有真实行情窗口试点、序列模型训练或序列策略账户结果；平台的旧表格模型与账户流程继续保留。

## 星期五收盘后，X长什么样

假设我们要给甲股票下一周打分。原表格模型看到一行汇总，例如过去20日收益、当日振幅、成交额比例。新接口允许明确选择收盘价、开盘价、成交量，把过去20个市场交易日排成20行×3列。一次取512个股票日期样本，得到512×20×3；20和512是默认值，3是例子，实际特征由调用者选择。

## 缺一天会怎样

若星期二没有记录，星期二仍占一个格子并保存缺失原因，不会用星期一冒充星期二。若星期三记录星期四才可知，它不能进入星期三决策，但之后可使用。未来才出现的龙虎榜记录与尚未覆盖记录使用同样未知掩码，不能提前暴露未来事件会发生。

## 一个已经验证的手算案例

窗口取Jan3、Jan4、Jan5三格，选择收盘价和成交量。Jan3无行情记录，保持两项未知；Jan4为12.5元、200股；Jan5为13.5元、300股。当Jan5记录15:01可知、决策15:30时可用；当记录15:30才可知、决策15:01时该格仍未知。以上是人造检查数据，不是市场预测结果。

## 它怎样交给不同模型

接口输出数值、是否观察到、缺失原因、日期位置和来源版本。后续可以先在训练段学习归一化和填补，再将同样X展平交给线性模型或MLP，或交给GRU/TCN。当前接口不训练、不填补成0、不自动生成Alpha、不改变候选名单、持仓数量、Y或调仓频率。

## Y和交易频率仍独立

过去20天是X，未来持有区间是Y。当前E19的Y连接下一次周调仓开盘与再下一次周调仓开盘，使用参考收益链；无公司行动时10元到10.3元是3%。使用20天X，不意味着每天交易，也不意味着预测20次。

## 第一版的输入边界

它只接收已经在内存中的有限每日特征分区，不是全市场快照流式读取器。daily_primitives明确声明日频，可以连接。legacy16旧适配器没有这个声明，仍会被拒绝；我们没有偷偷重标或更改旧特征计算。原始价格仍未复权，后续模型表示必须单独处理公司行动和相对价格路径。

## 默认资源界限

默认过去20个市场交易日、每批最多512样本和200万单元；来源分区最多50万行、3200万特征单元。只在请求一批时展开窗口。监督是采样软限制，不是操作系统硬隔离；真实数据试点另立预算。
