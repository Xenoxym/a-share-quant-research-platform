# Qlib六公式真实接口：72组小样本比较通过

12只股票、120个交易日的实际日收盘价，通过固定Qlib0.9.7的本地数据提供器和表达式接口生成六列。已保存实际值、独立参考值和未来数据扰动值；72组全部满足绝对/相对1e−5容差，缺失位置一致。改变第61天起的数据后，前60天六列逐位不变。这是小范围接口与因果方向检查，0模型训练、0账户回测、0收益结论。

## 用人话说实际做了什么

先把每只股票120天的收盘价放入Qlib规定的本地文件格式。然后让成熟库计算下表六列，另外用独立代码计算同一列，并逐股比较。比如某天收盘价10元、五天前9元，第二列是9÷10−1=−10%；它描述过去价格的相对变化，不是未来收益Y，也不是直接买卖指令。

20日均价低于当天价格，第三列就为负；斜率表示近期价格拟合线的方向，除以当前价后是相对尺度。R平方表示价格线对这一段数据的拟合程度；残差表示当天价格相对拟合线的位置，再除以价格。这些只有计算含义，还没有证据表明能提高选股收益。
