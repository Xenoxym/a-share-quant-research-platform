## 数据与历史资格

输入只有 `daily_kline`、证券主表、逐日状态、交易日历、公司行动和基准价格指数。无需龙虎榜文件，也不把曾上榜股票作为候选池。

证券范围取独立主表中的沪深主板股票，按当日上市/退市状态判断；保留历史退市股票，不按今天是否存活筛选。买入要求当时非 ST、行情有效、限价制度已验证。日线数据文件中的金额为元、成交量为股。

每次冻结输入文件 SHA256、数据副本、完整定义、源码与环境。指纹能证明使用了哪份数据，不能证明供应商没有遗漏或修订历史。主表在窗口内没有行情的股票单列数量，其中可能包含窗口外已退市或尚未上市股票，不能把这个数量全部当成缺数。

本版只支持已核查的沪深主板日频模型；不将科创板、创业板、北交所或特殊限价制度冒充已支持。公司行动缺文件不通过“未来是否缺文件”删除历史股票；实际持有时记录质量标记。

基准文件自身没有代码列，页面采用“来源基准价格指数”的名称。项目更新器 `tools/refresh_official_benchmark.py` 请求 `000300.SS`；后续需把标识和价格/全收益口径直接写入数据契约。当前指数曲线按研究首日收盘归一，不含分红和成交费用，也不冒充 ETF 账户。

## 指标的完整定义

令 i 为股票、t 为市场交易日序号：

- C(i,t)：原始收盘价，元/股。
- P_ref(i,t)：当日昨收参考价，元/股。可能因公司行动调整，不能无条件替换为前日原始收盘价。
- A(i,t)：当日成交额，元。
- V(i,t)：当日成交量，股。

参考价衔接收益及价格序列：

```text
r(i,t) = ln[C(i,t) / P_ref(i,t)]
X(i,t) = exp[Σ(u≤t) r(i,u)]
```

X 用于连续价格信号，起点常数不影响下面的排名和均线比例。它不是已验证的官方全收益指数；账户分红和送转另外计算。缺失收益不能靠填零得到合格历史；任一所需窗口价格缺失或市场交易日不连续，信号资格失败。

动量指标：

```text
M(i,t; L,S) = exp[Σ(j=S..L−1) r(i,t−j)] − 1
           = X(i,t−S) / X(i,t−L) − 1
约束：0 ≤ S < L
```

例如 L=252、S=21，恰好累乘 j=21,…,251 的 231 个日收益；不是把最近 252 日收益再额外向前移动 21 日。

```text
动量排序：score = M
反转排序：score = −M
可选分数过滤：score > θ；θ 为空时不设门槛，允许负分入选
可选均线过滤：X(i,t) / SMA_m[X](i,t) − 1 > 0
SMA_m[X](i,t) = (1/m) Σ(j=0..m−1) X(i,t−j)
m=0 表示关闭均线过滤
ADV20(i,t) = (1/20) Σ(j=0..19) A(i,t−j)
AV20(i,t)  = (1/20) Σ(j=0..19) V(i,t−j)
资格要求 ADV20 ≥ 设置门槛、AV20 > 0
```

至少需要 max(20,L,m) 个连续市场交易日的有效历史。流动性约束是共同交易资格，不解释为已发现的 alpha。

每个调仓决策日，在资格与过滤通过的股票中按 score 降序排名；同分按股票代码升序，取前 K 只。没有偷偷添加机构、上榜、财务估值或行业信号。

## 参数从哪里来

| 参数 | 默认值 | 来源和状态 |
| --- | ---: | --- |
| L / S | 252 / 21 | 约十二个月动量、跳过约一个月的日频近似，参考公开动量研究；未针对本数据调优 |
| 排序 | 动量降序 | 首个待检验技术假设，可改反转 |
| 分数门槛 / 均线 | 无 / 关闭 | 不额外叠加择时条件 |
| 调仓 | 月度 | 与低频动量参考一致；周度是另外的研究配置 |
| K | 20 | 用于可读、可执行的初始研究组合，约 5% 单股目标；不是经验最优值 |
| 配置比例 a | 98% | 初始现金缓冲设定；不保证实际持仓达到该比例 |
| ADV20 下限 | 2000 万元 | 流动性研究假设，非交易所规则 |
| 初始资金 | 100 万元 | 账户模拟规模 |
| 研究起点 | 2020-01-01 | clean 行情起于 2019 年，留出长窗口暖启动；历史不足仍拒绝信号 |

参考：[AQR Momentum Indices](https://www.aqr.com/Insights/Datasets/Momentum-Indices-Monthly)。该来源采用过去十二个月、排除最近一个月的总收益排名。本实现复用指标思想，但以本地日频参考价衔接收益近似；股票池、权重、风险管理和收益口径不同，不宣称复现论文/指数表现或已经证明适用于 A 股。

## 调仓与执行的形式化约定

1. **决策时点**：月度为每月最后一个市场交易日；周度为每个自然周最后一个市场交易日。假设日线于当日 15:30 可用，保存为 `known_at_assumed`。该时间不是供应商实测发布时间。
2. **最早执行**：下一市场交易日开盘模型。实验最后一天若不是实际周期末，不把它伪装成调仓日。
3. **目标**：入选股票每只 w=a/K；不足 K 只时不把剩余权重重新分摊。以决策收盘权益 E(t) 和原始收盘价决定：

```text
Q_target(i) = 100 × floor[E(t) × w(i) / (100 × C(i,t))]
```

未入选股票目标为零；目标股数为零表示预算不足一手。公司行动调整相关目标股数。

4. **提交与成交**：每日比较目标股数与实际股数。减仓先模拟，随后模拟买入。买单股数与预算先用开盘前现金和前收盘的 110% 预留确定；当日卖出所得不参与当日买单预算。限制最大持仓数量，未退出持仓会占用名额。
5. **时间与数量**：买入 100 股整数手，T+1；最终零股可以随全仓卖出。部分减仓仍按整手；小于一手的残差可暂时保留并记录。没有固定五日退出。
6. **目标持续性**：未完成目标逐日重试，直到完成或被下一次调仓目标覆盖。过滤条件不在两个调仓日之间自动触发退出；止损、盘中风控、自定义退出尚未实现。
7. **成交限制**：停牌不成交，涨停开盘拒绝买入、跌停开盘拒绝卖出，未知制度拒绝普通成交。买入股数受事前 AV20×参与率限制，实际成交再受当日总量上限限制。退市后不使用残留正常报价虚构成交。
8. **估值与权益**：未强制期末平仓。停牌期间沿用经公司行动调整的估值，避免停牌旧价与新股数叠加虚增净值。分红计扣准备金后的应收，不作为立即可复投资金；送转按除权日到账并向下取整是假设；不参与配股。未解决的退市或缺价估值单列。

原始开盘价是日线模拟的参考成交价。模型的卖买顺序、总量容量上限和涨跌停判断无法验证实际开盘队列、开盘可成交数量或订单撮合顺序；后续需要分钟/逐笔及更细的成交模型验证。

## 费用：明确记什么，不记什么

令 N=成交股数×原始开盘价，仅对实际成交部分计费：

```text
commission(N) = max(minimum_commission, commission_rate × N)
other(N)      = other_fee_rate × N
stamp(N,d)    = 1{卖出} × τ(d) × N
slippage(N)   = slippage_bps / 10000 × N
F             = commission + other + stamp + slippage
```

τ(d) 在 2023-08-28 前取 0.001，此后取 0.0005。[税务总局公告](https://shanxi.chinatax.gov.cn/web/detail/sx-11400-545-1780448)

佣金最低额、其他费率及滑点均为可配置模型参数；其他费不是经过逐项还原的所有历史收费。费用使用连续金额计算，未模拟券商逐笔分币舍入。滑点作为现金费用记一次，成交价保留原始开盘价，不再重复加价或减价。

| 情景 | 佣金 | 其他费 | 卖出印花税 | 模拟滑点 |
| --- | --- | --- | --- | --- |
| 零交易费用与滑点 | 0 | 0 | 0 | 0 |
| 零滑点 | 配置值 | 配置值 | 历史模型 | 0 |
| 配置成本 | 配置值 | 配置值 | 历史模型 | 配置值 |

三种情景共享策略信号，但分别重算现金、股数、目标及后续成交；不是从同一条曲线上直接加减费用。零交易成本仍保留停牌、限价、整手、容量、资金、分红税准备金及权益模型，不能称为完全无摩擦市场。

累计交易成本包含模拟滑点，不含单列的市场冲击、买卖价差实测、未成交机会损失或分红税准备金。分红准备金在净应收权益中体现。成交限制的影响通过资金路径体现，不伪装成可精确相加的一项手续费。

账户核对：

```text
权益 = 现金 + 净应收分红 + 持仓市值
权益 = 初始资金 + 已实现交易损益 + 未实现交易损益 + 净应收分红
```

交易损益已经包含成交费用，不再重复扣除。目标股数、实际提交、实际成交分开保存。

## 架构与下一阶段边界

```text
contracts.py  → 策略 / 执行 / 实验三个独立配置
data.py       → 独立历史股票池和不可变数据快照
signals.py    → 显式指标、过滤、排序、决策日候选
market.py     → 报价和可交易状态
portfolio.py  → 目标、订单、股份、现金、公司行动、费用
runner.py     → 三情景运行、归档、重放
server.py     → 本地交互与只读证据查询
```

新的模块不导入旧机构策略模块；通用指纹和报价辅助代码初始从已有实现提取，并按新合约独立维护。旧输入、标签及机构配对没有进入新信号。

当前创建器支持历史收益排序及可选均线过滤；它还不是任意多因子 AND/OR 图、任意退出条件或机器学习流水线。以下能力仍待实现：

1. 在同一股票池、时间和执行协议下，建立等权参考、简单趋势、动量、反转等预先登记的对照；单独分解规模、波动、行业等暴露。行业历史未核实前不补当前标签。
2. 因子分组与排序有效性、信号至成交收益漏斗、尾部交易诊断、容量和参数区域稳定性；分别回答信号和执行层问题。
3. 全部尝试登记、时间重叠处理、多重试验校正、滚动验证。已被查看的历史只能标为回顾性；真正未见验证依赖后续新增数据。
4. 补齐到账日期、退市结算、来源标识和数据可用时点；在缺数据的边界保持可见限制，不以平滑曲线掩盖。
5. 前向模拟逐日保存实际可得信息、决策和订单，再与事后回测比较。

工程验收不以盈利为条件。任何声称策略有效的结论，必须经过独立数据检查、稳定性与净收益/容量验证；不通过反复调同一历史区间直到盈利来完成验收。
