# 同一份输入，让不同模型公平地学习：E15模型接口

现在可以把同一张股票特征表和同一列学习目标，交给六类模型。这里完成的是接线和训练侧处理；时间切分、成熟标签、原生账户以及真正的收益比较依次接续，不能把合成检查当作新策略成功。

## 先用一只股票理解输入

假设每行是一只股票在一次决策时刻的信息，三列分别是过去价格变化、成交变化和龙虎榜集中度。也可以换成原16项、新板型包、财务包或它们的明确组合，模型接口没有把这些列写死。

如果某只股票没有可用龙虎榜数值，该格保留缺失。训练时，中位数填充器只看传入的训练行，同时为每个输入增加一列“这里是否缺失”。预测时继续使用训练时的填充值，不拿后来的数据重新计算。不同缺失原因仍保存在来源层；本模块的缺失旗标只表达数值缺失，不把“无上榜”“数据缺失”等原因自动混成已认证同义项。

线性模型还把特征按训练均值和标准差缩放，避免成交额的数值大小影响正则化；树保持原数值尺度。训练中全空的列明确拒绝，下一层需要根据训练段覆盖率公开记录排除哪些列，不能悄悄删列或借测试段决定。

## 六种学习器

| 模型 | 为什么放入共同接口 |
|---|---|
| Ridge 岭回归 | 简单线性对照，约束系数幅度 |
| ElasticNet 弹性网 | 同时约束系数幅度并允许部分系数缩为0 |
| Huber 稳健回归 | 减少很大残差对回归的影响；不删除真实极端行情 |
| RandomForest 随机森林 | 多棵采用自助样本的树进行平均 |
| ExtraTrees 额外随机树 | 使用更随机的分割，提供另一种树对照 |
| HistGBDT 直方图提升树 | 后续树逐步修正残差，保留原受限提升树路线 |

没有哪一种在这里被宣布更赚钱。模型参数固定为白名单中的有限配置，名字变化不改变模型身份。HGB关闭随机内部早停，避免把打乱时间的内部验证当作金融时间验证；未来如需早停，应另建显式过去验证协议。森林内部任务数固定1，数值库线程最多2，整体进程并发另由执行层控制。

## 如何使用

```python
from src.alpharesearch.models import model_spec, TabularRegressor

spec = model_spec("ridge", params={"alpha": 10.0})
learner = TabularRegressor(spec)
learner.fit(X_train, y_train)       # 只在这一步学习参数和填充/缩放值
scores = learner.predict(X_later)  # 列名、列顺序必须与训练时完全一致
receipt = learner.metadata()       # 参数、列、预处理、代码及环境身份
```

X是有列名的数值DataFrame；Y是与X行索引完全相同的Series。可选样本权重必须正且有限，仅作用于回归器，填充和缩放使用未加权训练统计。每个实例只允许一次实际拟合；失败也记录一次尝试，不能在同一实例上隐式重试。当前接口并不负责检查X的历史可用时点和Y是否成熟，这些由E16承担。

## 验证什么

合成样本人为设置了可学习的规律，六类模型要能学到它并在另一段合成数据上优于训练均值预测；这一项防止“代码能运行但接错了列或目标”。还检查预测新缺失与极端值不会重新拟合预处理、列错位拒绝、全空列拒绝、目标错位拒绝、有限预算以及失败计数。

模型元数据记录源码、Python和数值依赖版本，没有将它解释为整个操作系统或供应商数据已冻结；此阶段没有加载外部模型文件。

设计参考[scikit-learn官方泄漏说明](https://scikit-learn.org/stable/common_pitfalls.html)、[缺失标记](https://scikit-learn.org/stable/modules/generated/sklearn.impute.MissingIndicator.html)、[HGB的早停定义](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingRegressor.html)和[Huber回归](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.HuberRegressor.html)。实际本机是scikit-learn 1.9.0，官网stable页面当前显示1.9.1；采用两者共同已有的接口，不依赖更晚的显式验证参数。

## 独立审查后的接口补充

支持日期×股票等复合索引，逐层检查键缺失并保留预测索引。连续参数统一为浮点数后生成身份，尤其森林max_features明确表示比例：1和1.0都规范为全部特征；特征个数语义不通过这个比例字段传入。初始化失败会保存错误并禁止同实例重试，但不会虚构已经发生一次拟合；实际拟合失败仍计数。
