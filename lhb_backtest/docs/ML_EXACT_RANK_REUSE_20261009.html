1. 为什么要做，实际改了什么

此前32个价量公式的完整筛选与核查约19.5分钟，接近单例20分钟预算；八类研究只完成第一类。观察发现，32种分数的496种配对，需要在旧算法中重复排序992次。很多配对其实使用完全相同的股票名单，同一种分数的排名可以复用。

正式代码只修改筛选器的相关性计算，新增一个局部缓存模块和反例测试。每次调用结束就释放缓存，缓存最多保存1600万个排名值；共同缺失名单不同就重新排序。选股、学习目标、训练收益路径、筛选名额和账户引擎规则均未修改。旧登记仍使用自己的冻结代码，完整结果核查仍然保留。

2. 用一个例子理解为什么不能随便缓存

假设有四只股票，分数A是1、2、100、4；分数B是1、缺失、0、2。计算A和B关系时，第二只必须从这一对中排除。剩下三只的A排名是1、3、2，B排名是2、1、3，相关性为−0.5。若套用A在全部四只中的排名，就会得到不同的答案。

所以程序只复用“同一种分数、完全同一张共同可用名单”的排名。它保留原始数值类型、并列平均排名、常数与不足行的诊断；大整数、不同缺失、缓存淘汰和跨调用污染都列入检查。这是在减少重复工作，没有改变对股票的判断规则。
