# 基础策略研究 V4

先比较不同收益机制，再在有依据的方向内研究参数。之前的 24 个实验只是动量／反转的窗口、均线和频率网格，不能代表 24 种独立策略。现在保留它们作为“参数对照”，新增“基础策略研究”。

## 这轮到底在试什么

2020-01-01 至 2026-09-24，预先登记 15 个账户：10 个候选、5 个对照。规模的三个版本、价值的两个版本互有关联，不能称作 15 项独立发现。每个账户同时独立计算含费和零交易成本路径。共同股票池、252 日连续历史、财报资格、流动性和执行规则一致；短期反转按周交易，其余股票账户按月。

| 机制 | 可计算的信号 | 公开依据与本项目的差别 |
|---|---|---|
| 小市值 | 收盘价 × 最近已公布总股本，升序取 100 只 | [Size and Value in China](https://www.nber.org/papers/w24458) 研究中国规模与价值，构建因子时排除最小 30%；本项目另将“最小100只”和“排除底部30%”配对，区分极小盘效应。不是论文多空组合。 |
| 小市值与盈利资格 | 年度归母净利润为正，再按估算市值取最小100只 | [Size Matters, If You Control Your Junk](https://www.aqr.com/Insights/Research/Working-Paper/Size-Matters-If-You-Control-Your-Junk) 启发质量控制；单一盈利正负过滤远不是论文的完整质量定义。 |
| 价值 E/P | 最新已公布年度归母净利润 ÷ 估算市值，取最高正值 | 中国规模与价值研究提供机制依据；年度盈利不是 TTM，主板多头也不是原文复现。 |
| 价值 B/P | 最新已公布股东权益合计 ÷ 估算市值 | [French 因子资料](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html) 提供公开构建说明；权益含少数股东，未做论文全部会计调整。 |
| 盈利能力 | 年度归母利润 ÷ 同年度权益合计，取最高正值 | 盈利能力的简化原型；不是准确归母 ROE、毛利润/资产、QMJ 或 FF 经营盈利能力。 |
| 低波动 | 63 日参考价日对数收益样本标准差，取最低值 | [Ang 等人的波动研究](https://www.nber.org/papers/w10852) 是相关研究起点；论文特质波动与本实现总波动不同，也不是有杠杆的 BAB。 |
| 动量 | 最近252日参考价收益连乘，跳过最近21日 | [AQR 动量数据与方法](https://www.aqr.com/Insights/Datasets/Momentum-Indices-Monthly)；本实现采用交易日近似和主板多头账户。 |
| 短期反转 | 最近5日参考价收益的相反数 | [Reversals and the Returns to Liquidity Provision](https://www.nber.org/papers/w30917) 提供流动性机制与检验思路；5日、周调仓是待证伪的实现设定。 |
| 市场趋势择时 | 市场价格参考高于126日均线则持同种子随机底仓，否则目标现金 | [Time Series Momentum](https://www.aqr.com/Insights/Research/Journal-Article/Time-Series-Momentum) 研究自有历史趋势；MA股票多头/现金代理与跨资产期货时间序列动量不同。 |
| 对照 | 零息现金、三个固定哈希种子随机组合、大市值100只 | 随机组合每次使用相同代码顺序，不是逐月随机洗牌。规模对照依据 [French 规模组合说明](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/det_port_form_sz.html)，但不是其年度NYSE断点规则。 |

每只入选股的目标为账户权益的 0.98/100；月末收盘决策，下一交易日开始执行，落选目标清零。并非固定持有五日。具体账户定义、来源、资格、交易成本和限制可在界面展开，每次运行还会冻结源码、数据快照、候选表、订单与逐股流水。

## 市值和财务数据能支持什么结论

读取本地 SimTradeData 已导出的财报原始字段，不使用今天的股本回填历史，也不把供应商 PE 直接作为信号。财报公告日必须严格早于决策日；没有小时级公告时间，同一天公布的报告本日不用。季度股本最多距报告期末240日，年度财务最多550日。遇到无公告日期、重复期间等情况，不静默推测。

当前市值是“已披露季报股本 × 当前原始收盘价”，不是精确历史股份登记总市值。增发、注销、送转股在下一季报前可能使它偏离；本地历史财报没有首次披露版本档案，公告日过滤不能消除后续修订偏差。候选表保留股本值、报告期、公告日、陈旧天数，便于研究者直接核查。尚无可靠历史行业分类，不能宣称完成行业中性检验。

保留历史退市样本，但证券主表完整性仍受供应商覆盖限制。股票范围是沪深主板，不包括创业板和科创板。日线成交模型还不能证明开盘可成交队列、真实冲击或容量。分红扣税准备金后留作应收，支付日缺失导致不能复投；这对高分红策略尤其重要。

## 系统如何决定下一步

先验证数据与账本，再分析信息、成本、风险与可实施性。不能用一个总收益排行榜取代研究：

1. **无效实验**：未来数据、错误价格单位、财报时间错误、账本不平或未解决估值，优先修复；暂不判断策略本身。
2. **有增量线索**：比较同池随机账户参考、逐年与局部区间、零费/含费、仓位和个股贡献，寻找可反驳的机制解释。
3. **研究优先级**：以候选相对随机参考的日收益差为基础，21/63日循环时间块联合重采样1500次，给出跨候选同时不确定带。带跨零不等于失败；带为正也只是机制复核的优先级，不是实盘准入。
4. **只追加能区分解释的实验**：先登记问题、改变项、保持项、停止条件，再计算。保留失败和提出假设的时间，不回写首轮协议。
5. **真实前向验证另行开始**：所有当前历史已被查看。2024年分段只是描述性后续区间，不能叫未见样本外，更不能反复用它筛选冠军。

参考曲线是三个随机账户逐日收益等权的分析组合，非另一个撮合账户或官方指数；统计量是日收益差均值×252，不是 CAGR 之差。时间块推断保留一定时间相关性和同日横截面相关性，但不能修复非平稳、先前研究筛选、缺失股票和原始数据错误。

## 使用

工作台左侧进入“基础策略研究”：查看全部账户与来源 → 点击方向查看年度/较差区间证据 → 打开具体实验 → 框选日期 → 点击股票，查看原始行情、财报来源、订单和流水。追加研究复核与实验链接也在同一页面。

```powershell
..\.venv\Scripts\python.exe tools/technical_research.py foundations
..\.venv\Scripts\python.exe tools/verify_foundations.py data/technical/foundations/<suite_id> --output data/technical/validation/v4/accounts.json
```

输出在 `data/technical/foundations/<suite_id>/`。`protocol.json` 在运行前保存；`result.json` 包含全部账户和机器可读证据；研究者的后续解释另存 `research/*/foundation_review.json`，界面按批次编号关联。重复运行留下新批次，不覆盖旧证据。
