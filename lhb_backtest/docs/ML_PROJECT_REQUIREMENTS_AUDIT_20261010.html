现在能实际运行的基础链

已有市场数据 → 按当时可见信息整理特征 → 在过去成熟样本上训练 → 给后续股票打分 → 排序形成持仓 → 运行资金账户 → 核查收益、回撤和对照。

例如当前R24T：2020—2022年的379842条成熟股票—决策日记录用于训练；之后给2023—2026年的550711条记录评分。每只股票每次输入一行36项摘要，不是36项乘五天；共同合格主板名单不先筛最小市值。按分数取100只、约98%目标等权，在计划周调仓开盘尝试调整。

原始经济Y为计划买入开盘到下一次计划调仓开盘的收益，假日按实际计划。新接口另存原始Y和中心化/标准化/排名训练Y；当前第一个模型只改成中心化Y。这里没有固定周一开盘到周五收盘，也没有直接优化账户年化或最大回撤。历史旧实验保留原目标，不统一改写过去。
