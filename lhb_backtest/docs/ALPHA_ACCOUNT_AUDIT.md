# 从模型名单到可检查的收益与回撤（E18）

2026-10-07验收更正：本阶段使用手写字典收据的合成分数，未覆盖真实训练器的列表收据。E19实际桥接发现并修复入口错误；旧测试只证明局部名单/账户能力。详见[接线错误与修复](ML_ACCOUNT_BRIDGE_INTEGRITY_20261007.md)。

模型周五给四只股票评分，决定下周一买其中两只。我们需要回答三件具体的事：模型到底选了谁，账户是否用了相同的名单和行情，最后的钱与股份有没有算错。

这次提供两个接口：`prepare_score_account` 准备现有账户的输入，`audit_score_account_run` 独立检查生成的账户档案。它们不训练模型，不下真实订单，也不自动开始新的真实研究。

## 沿着一周走一次

1. 已完成学习的结果中保存每只股票的分数、日期、决策时间、计划买入与目标结束时间。分数不是账户收益。
2. [E17组合接口](ALPHA_SCORE_TO_ACCOUNT.md)按事先给出的资格名单选择股票。新核查器另写一套遍历规则，独立计算每期排名、并列、入选与权重，核对全部输出；没有再次调用同一个选股函数来证明自己。
3. 读取登记快照，核对日历、必要行情和公司行动文件的内容指纹。模型组合使用的原始收盘价必须与快照同一天、同一只股票的原始价格相等。股票数量、配置比例、周/月频率、账户开始结束日期也必须一致。
4. 原生账户按现有会计规则执行。它继续约束现金、整手、容量、停牌、涨跌停、费用和公司行动。模型不会因为接上账户就自动全仓成交。
5. 独立核查器从成交和流水重算现金、应收、股份、每日权益、净值、收益与最大回撤，还检查原始开盘成交价、费用、目标股数与所选股票的对应关系，以及实际买卖量不超过当时目标差额。普通日核对原始收盘估值，停牌和公司行动日核对按规则调整后的结转价格。

比如周五A、B排名最高，各分配49%，下一周C、D排名最高，账户会尝试卖出A、B并买C、D。不能拿“模型分数更高”代替这个过程中实际留下的钱。合成测试特意加入换股和价格下跌，用来验证收益与回撤核查，不代表现实策略有收益。

## 原始名单和实现保存在什么地方

原生账户档案里增加六项证据：

| 文件 | 用来回答的问题 |
| --- | --- |
| alpha_predictions.parquet | 每期完整评分是谁，何时预测，来自哪个训练身份？ |
| alpha_references.parquet | 资格与原始参考收盘价是什么，何时可知？ |
| alpha_learning_receipt.json | 模型、特征名单、成熟标签和训练/预测身份如何声明？ |
| alpha_portfolio_receipt.json | 股票范围、筛选、排序、配置比例和目标周期如何声明？ |
| alpha_account_receipt.json | 上述内容与账户参数、行情快照、独立选股核查如何关联？ |
| alpha_scoring_code.json | 对应声明的评分接口源码及其指纹是什么？ |

账户原有decisions、schedule、targets、fills、ledger、positions、equity继续保留。档案说明会写清模型评分与提供的资格条件，避免模型账户还显示旧的动量公式或默认资格条件。

账户Market中的20日均量只用于既有容量约束，不悄悄增加模型X。这里没有新增小市值母池。模型特征可以包含龙虎榜；行情快照本身没有龙虎榜文件，不能据此断言模型完全没有龙虎榜信息。

## 开发者如何连接

```python
from src.alpharesearch.account import prepare_score_account
from src.alpharesearch.audit import audit_score_account_run

prepared = prepare_score_account(
    learning_result, references, calendar, portfolio_policy,
    registered_snapshot, native_account_spec,
)
# 正式执行器将prepared传给既有technical.runner.run，并登记有限预算。
# folder是原生账户产生的冻结目录。
audit = audit_score_account_run(folder)
```

账户ResearchSpec的Strategy采用原生默认字段，仅显式修改name、top_k、allocation、rebalance以承载分数组合；其他隐藏策略设置会拒绝，模型/资格规则由评分证据说明。账户日期必须具体，不用latest代替冻结日期。账户核查目前覆盖零交易费用与配置费用两种情景。

## 这份核查证明到哪里

能够证明的是归档内容的一致性、独立的名单/权重重建，以及相对于所提供快照的账户算术和成交/权益关联。预测表可以在内部一致的情况下写出虚假分数，所以这份核查没有证明模型真的按声明完成训练，也没有重新训练树或重放模型数值。

文件指纹不能证明供应商没有修订历史，资格时间仍然依赖调用方的历史声明；持仓停牌与公司行动估值按已声明规则独立重建，但这不能证明规则对现实排队成交或未解决权益的经济估值完全准确。这些边界与模型是否在真实市场提高收益是不同问题。

当前阶段以有限合成档案验收接线，不宣布新策略成功。下一步完成持久执行、恢复和筛选预算后，运行扩充特征/多模型与旧16特征、小市值、固定随机seed11的同口径真实对照，比较含费收益、回撤、各年份表现和持仓来源。


独立复核初轮发现余额自洽仍可能伪造收盘估值、超目标买入或过早卖出，展示JSON也可能与已审计表不一致。本阶段保留初轮拒绝，增加快照估值/活动目标/费用与损益/展示权益核查，以及送转与停牌、零股退出、部分买入留现金反例。这些是工程缺口修复，不表示旧策略报告已经出现同样错误。
