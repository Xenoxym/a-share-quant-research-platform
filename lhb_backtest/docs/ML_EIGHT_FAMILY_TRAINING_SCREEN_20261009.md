# 八类组合特征：256个公式已完成训练筛选，下一步进入模型与账户

这轮把八个特征家族的真实训练期计算和筛选全部跑通了。256个带正负方向的表达式对应128个模板，并不是256个独立有效策略。本轮没有训练新模型，也没有新增账户回测；原12个模型账户亏损的结论不变。下表只能用于决定接下来试哪些X，不能当作盈利成果。

## 1. 用每周的一次选股说明这轮实际做了什么

例如2020年1月3日星期五收盘后，我们把当时共同合格的主板股票逐只拿出来，使用那个时点已知的日线摘要、板型、龙虎榜或财务原料计算公式分数。这里先没有机器学习模型：公式是明确写出的算式。它们可以在下一阶段成为模型输入X，也可以在另一条独立路线中直接成为选股分数。共同名单不是先选最小市值股票。

对每一个公式，筛选器从该周分数最高的股票中选最多100只，每只占1%的理想权重；不足100只的空槽算现金。再用已经成熟的历史Y计算1月6日下一次开盘到1月13日下一次开盘的组合涨跌。目标是下一次计划入场到再下一次入场的收益率，不是第五天的绝对价格，也不是周五收盘卖出。遇到休市按交易日历顺延。

同样的操作覆盖2020—2022年的153个周度日期、379,842条股票日期记录。每个公式留下分数覆盖、选股名单、153周路径、缺失原因、是否进入后续候选等记录。公式定义和选择规则在执行前已经冻结；2023年1月6日起预测期的标签没有参与本轮筛选。那段历史此前已经看过，因此后续研究仍须称为回溯时间划分验证，不能叫新的盲测。

## 2. 这次确实扩展了哪些信息

八类各32个方向表达式。价量与风险之外，还有连板/板型与交易信息、龙虎榜席位集中度与机构结构、买卖两侧差异、已公告财务与估算市值、全市场状态，以及多种原料的交互。龙虎榜w1/w3指单日或三日披露窗口，不是回看1/3天；这里是20个交易日观察范围内的最近可用报告，不等于每周末当天报告。

实际例子：价量11号表达式把20日收益的相对排名，与成交量异常排名和成交额异常排名之间的差组合；龙虎榜席位07号则把已知单日披露窗口的机构买入金额占比与成交额活跃程度组合。它们是明确的交易机制假设，没有模型替我们决定公式。表里的编号代表公式，不是股票；正反方向也不是两条独立信息。

“表现路线”按训练期总毛收益与周端点回撤的取舍筛选，每类最多2个；RankIC不作为硬门槛。“探索路线”按事前保留的多样性名额，每类最多1个，可能训练收益为负。被保留不等于胜出。我们还没有实现自适应遗传编程、强化学习或LLM公式搜索；现在是有限、预先列出的组合库。

本批实际保留12个表现路线候选与8个探索候选。表现路线也允许保留收益与回撤取舍上的候选，并不要求正收益：龙虎榜买卖结构的两个表现候选，三年训练总毛收益仍约为−30.8%和−28.4%。保留它们只是检验信息或组合价值，不是把负收益称作策略成功。

## 4. 市场条件关闭以后：零分仍然选股

部分算式是“市场条件成立时使用单股排名，否则分数=0”。当前筛选器把0当作有效分数；某周所有股票都为0时，它会按股票代码顺序选前100只。它没有自动持现金。常数分数周无法计算RankIC，会从IC平均中排除，但这些周仍进入收益路径。因此较高RankIC不能单独证明这类公式能避开市场下跌。

作为模型输入X，这种条件交互项仍可以保留，模型还能使用其他X。作为直接选股策略，必须另行固定条件关闭后的资格或仓位规则，并与代码顺序选股和相同风险敞口的对照比较。不能从分数0反推条件一定关闭，也不能事后改写这批已冻结的结果。
