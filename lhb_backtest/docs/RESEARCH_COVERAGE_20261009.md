# E19整批研究后的覆盖复盘

这是已经完成的有限批次复盘，不是新策略成功报告；下一项研究仍单独登记。

| 已覆盖的方向 | 实际投入与结果 | 尚未回答 |
|---|---|---|
| 价量／模型类型 | 原16特征六类表格模型；每类一次固定fit | 序列、神经网络与模型权重重载 |
| A股板型 | 原16＋29项，岭回归和提升树 | 本批均变差；不能推广所有板型无信息 |
| 龙虎榜 | 原16＋普通1/3日报告结构，两个模型 | 小幅减亏；事件缺覆盖不等于无事件，关系表示待做 |
| 财务／市场 | 原16＋14财务＋12市场，两个模型 | 较明显减亏但仍负收益；信息、规模暴露和仓位贡献需拆开 |
| 账户／验证 | 12模型＋4固定对照，32双费用情景；原档案全核查，同名单16方法 | 历史已经看过，源修订限制、单次拟合与未来观察仍未关闭 |
| 工程与资源 | 报价/名单查询修复；一次内存停止、一次主动停止留档；未重训 | 更大候选库仍要有限批量与资源实测 |
| 输入表示 | E20私有过去窗口接口，30手工反例通过，0真数据试点/fit/账户 | 生产接入、旧16频率声明、归一化、事件张量、真实数据验证 |

本批12个模型的扣费年化全部为负。零费用下10个仍亏损，另两个年化仅约3.25%和0.94%。这更支持先检查目标、信息有效性、排序和跨期变化；不能将失败只解释为费用，也不能由本批宣布所有机器学习无效。小市值、低波和半仓控制仍是具体规则下的对照，非永恒最优策略。

本批消耗原12个真实fit、32个真实账户情景；修正核查与统计为原档案读取，未追加训练/交易模拟。外围源码/入口审查和软件测试分别记录，不能把它们计成市场策略实验。当前0美元外部费用。

继续扩展视野而未执行的线索：

- [Qlib作者代码](https://github.com/microsoft/qlib/blob/main/qlib/contrib/data/loader.py)：读了输入配置与处理器相应代码。序列组织、尺度转换和模型结构需分开消融；本项目不直接沿用默认示例Y。
- [SimStock作者论文](https://arxiv.org/html/2407.13751v1)：选读表示、数据和组合评估章节。关系表示可用于分散组合；未复现，本研究不将其美日组合结果当A股收益证据。
- [AlphaGen作者论文](https://arxiv.org/html/2306.12964)及作者线性集合代码：选读集合优化、实验、案例与交易章节。单公式弱或相互相关高不必然无组合价值；仍要核验账户。
- [AlphaForge作者论文](https://arxiv.org/html/2406.18394v2)：选读滚动组合、实验和交易章节。滚动更新必须使用已成熟标签；作者实盘主张尚未由我们独立核验。

新增竞争解释：变化可能来自归一化而非模型、来自共同规模暴露而非事件、来自噪声追逐而非适应漂移。后续以同池／同目标／同账户下的简化对照否证，保留稀疏事件与组合增量通道；不能只按单公式IC删掉所有候选。
