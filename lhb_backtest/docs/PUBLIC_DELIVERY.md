# 公开源码交付约定

当前交付是本地可审阅候选。尚未创建远程仓库、推送、运行 GitHub Actions 或授予开源许可证。候选名称为 `a-share-quant-research-platform`，版本为 `0.2.0`。

## 目录与兼容

```text
repository/
  README.md                 产品入口
  AGENTS.md                 研究与交接规则
  .gitignore                本机运行文件排除
  lhb_backtest/
    pyproject.toml          发行包与依赖
    src/technical/          账户回测、核查与工作台
    src/mlresearch/         输入、目标、模型与研究矩阵
    src/researchops/        任务、冻结执行、证据、有限总控
    src/                    兼容保留的旧事件模块等
    tools/                  源码工作区命令
    tests/                  合成数据软件回归
    config/                 无凭据的配置模板
    docs/                   当前操作与长期规划
    samples/                旧事件接口示例
```

当前保留旧应用目录和内部导入名。wheel 包含 Python 模块与工作台静态资源；`tools/`、配置和指南通过源码目录交付。命令示例面向源码 checkout，不声称单独安装 wheel 就能获得完整研究工作区或数据。

## 什么可以发布

候选从明确的路径清单生成：源码、工具、测试、配置模板、示例、包装文件与选定文档。候选 manifest 给出逐文件 SHA-256。不会直接把整个工作目录或 `git status` 中所有文件上传。

行情、真实财务数据、数据库、快照、订单与账户记录、已训练模型、会话凭据、Codex 日志、机器资源盘点和费用偏好留在本机。公开文档可能提到历史任务或运行 ID；这些 ID 不包含实际证据，也不能在空工作区直接复现原研究数值。文档中未随候选提供的本机证据链接将标明。

文档包含两类内容：当前运行说明，以及注明日期的历史教程、结果和设计。规划不是已实现功能；历史报告不是当前版本回归证明。公开源码不自动取得市场数据的再分发权。

## 软件验证与研究验证

- 软件测试使用合成样本、临时数据库和模拟 Agent，不访问付费服务。个别模型测试会拟合小型合成数据；它们不计为真实市场研究。
- 安装验证核查发行包、依赖和静态资源，不能证明数据供应商正确、策略赚钱或所有系统均可运行。
- 新真实研究仍需明确数据快照、日期、假设、否证条件及有限预算，再通过 `register/run`。已看历史不会因为改名、修复或新会话成为未见样本。
- 最终发布检查记录验证平台、依赖版本和未执行项。未验证的 Linux/macOS、远程 CI 或真实账户不冒称已通过。

## 首次发布前

项目所有者审阅准确候选目录、文件清单、变更说明、测试证据及扫描边界，选择许可证并确认仓库名和首次发布。之后再创建远程或推送。是否保留旧 Git 历史也单独说明；源码候选的检查不能代替整个历史的检查。

已准备 Windows/Linux、Python 3.12 的软件 CI 定义，只运行合成测试、打包和模板输出；尚未在 GitHub 运行。动作固定到官方发布提交：[checkout v6.0.3](https://github.com/actions/checkout/commit/df4cb1c069e1874edd31b4311f1884172cec0e10)、[setup-python v6.3.0](https://github.com/actions/setup-python/commit/ece7cb06caefa5fff74198d8649806c4678c61a1)。这是可核查的依赖固定，不代表 CI 已通过。

后续建设按项目纲领推进：先完善数据与特征契约，再扩展 A 股事件和财务/市场特征，建设表达式与搜索流水线，接入多模型和组合研究。各阶段保留适当对照，重大策略成果以核查后的收益与回撤为准。
