## 为什么.data目录不能直接拒绝

wheel标准本来允许.data/scripts等子目录，由安装器移到环境对应位置；脚本的解释器首行还允许被重写。这三个文件正是这样的正常结构。[PyPA官方wheel规范](https://packaging.python.org/en/latest/specifications/binary-distribution-format/)。

下一任务将复用已经下载并校验的12文件，新增下载预算为0。安装仍交给标准pip，仅接受这三个已知脚本在新环境Scripts目录的映射，并核查脚本正文、其余档案成员和原基础库元数据。不会自己实现一个安装器，也不会把任意路径放行。[pip官方安装文档](https://pip.pypa.io/en/stable/cli/pip_install/)。
