机构披露净买额 · 固定假设模板
当前页面配置一个后台固定的研究模板。默认参数用于演示研究流程，未经策略有效性验证；这里尚不能自由组合价量选股、排序和退出规则。


这个模板实际买什么、何时卖
    

  1. 候选：当日已上龙虎榜的沪深主板普通单日榜事件；通过历史非 ST、席位、行情、估值和连续 20 日流动性检查。上榜本身不等于买入信号。
    2. 

  2. 信号：（买榜机构买额 − 卖榜机构卖额）÷ 当日成交额，大于下方设置的门槛，默认大于 0。这是披露部分的金额口径。
    3. 

  3. 排序：机构组合按上述占比从高到低安排买入；基础事件组和配对对照组按固定种子生成的顺序安排买入。
    4. 

  4. 入场：假设信息在下一交易日开盘前可用，尝试在下一交易日开盘成交；资金、持仓、限价和流动性检查可能使订单无法成交。
    5. 

  5. 退出：入场日之后第 H 个市场交易日开盘尝试卖出，H 为下方持有期。默认 H = 5；无节假日时，周一买入对应下周一开盘尝试卖出。无法成交会延期。
    6. 

  6. 此模板没有均线买卖、市场趋势过滤或止损规则；允许空仓，最大持仓数和单股比例是上限。
    7. 

这五组共享事件模板，其中“基础事件组合”仍然只选龙虎榜股票。它不能作为独立于龙虎榜的全市场价量基线。
